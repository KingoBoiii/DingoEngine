# API review — v1.0 P9 (the API pass)

**Date:** 2026-10-13 · **Branch:** `feat/v1`, audited at `57f2035` (P8's last commit) · **Scope:** every
public header under `include/` (157 headers): what a game can name, and what 1.0 will promise for the
whole 1.x line ([docs/versioning.md](../../docs/versioning.md)).

**Method:** three read-only auditors, one per area, read every header in full and checked each
claim against `src/`, `test/` and `examples/` (call-site counts leave out the defining file):
- **A1** — the root, `Core/`, `Windowing/`, `Events/`, `Audio/`, `Asset/`, `UI/` (57 headers). Two
  claims were checked by compiling: A104 against a shadow copy of `include/` (199 Linux TUs,
  `-fsyntax-only`) and A108 with a two-line repro.
- **A2** — `Graphics/` and `Graphics/Enums/` (44 headers).
- **A3** — `Scene/` and `Physics/` (11 headers), plus the plan's two additions (`SetActive`,
  `OnFixedUpdate`).

Every finding gets one verdict:
- **change before 1.0** — breaking it later needs 2.0, so it is fixed now (the plan's D8 allows
  breaks until 1.0.0; each goes into `migrating-to-1.0.md` in P11);
- **deprecate** — the old name keeps working, marked `[[deprecated]]` with its replacement, and goes
  in 2.0;
- **keep** — stays as it is, often with a rule written down instead.

Doxygen comments are P11's (D7) and not part of this review.

## Core, windowing, events, audio, assets, UI (A1)

### A101 — Application lifecycle {#a101}
Every `CreateApplication` had to call `app->Initialize()` itself, `Destroy()` was public while the
destructor called it too (a game calling both double-deleted its layers: `LayerStack::Clear` deleted
them without clearing the vector), and `RequestRestart` worked only if `CreateApplication` called
`ConsumePendingRestart()`, which only the test app did.
**Change.** `EntryPoint.h` only defines `main`/`WinMain`, which call `Internal::Main`: create,
`Initialize()` (public and idempotent), `Run()`, `delete`, looping while a restart is pending. The
constructor applies a pending restart's API. `Destroy()` is private; `LayerStack` moved to
`Internal` and clears itself; `PopLayer`/`PopOverlay` (0 callers) are gone. Every example's
`CreateApplication` is now `return new X(params);`.

### A102 — Engine-owned lifecycles {#a102}
`Window`'s constructor, `Initialize`, `Shutdown`, `Update`, `WaitEvents`, `SetEventCallback`;
`AudioEngine::Create/Initialize/Shutdown/Update/As<T>`; `AssetManager`'s constructor, `Initialize`,
`Shutdown`, `Update`; `Log::Initialize/Shutdown/OpenFile`; and `CacheManager` were public with no
callers outside `src/`. `Window::GetNativeWindowHandle` returned a `GLFWwindow*`.
**Change.** All private with `friend class Application`; the log's lifecycle is
`Internal::InitializeLog/ShutdownLog/OpenLogFile` (`Core/LogLifecycle.h`), `CacheManager` is
`Internal::CacheManager` under `src/`.

### A103 — `<Windows.h>` from a public header {#a103}
`Log.h` included it in Debug and Distribution but not Release, so a game could build in Release and
fail in Debug, and the test app got `min`/`max`/`near`/`far` macros. The plain-string assert's message
box said "No message".
**Change.** Both message boxes moved into `Log.cpp` (`Log::ReportAssertion`), with the real message.
`EntryPoint.h` includes `<Windows.h>` itself, with `WIN32_LEAN_AND_MEAN` and `NOMINMAX`, only in its
Distribution `WinMain` branch.

### A104 — Weak handle types {#a104}
`SetVolume(volume, sound)` with the arguments swapped compiled; `GetTexture(5)` and
`AssetHandle h = 0` compiled.
**Change.** `enum class AudioSoundId : std::uint32_t {}` (with `k_InvalidSound`), `explicit
UUID(uint64_t)`. The shadow compile: 0 of 199 TUs broke from `explicit`, 5 lines of
`MiniAudioEngine.cpp` from the strong id.

### A105 — `WindowParams` setters return by value {#a105}
`params.Window.SetTitle("x").SetWidth(800)` set the width on a temporary. **Change:** they return
`WindowParams&` (source-compatible; every game uses designated initializers).

### A106 — Version macros {#a106}
CI wrote the commit count into `DE_ENGINE_VERSION_PATCH` (1.0.503 for 1.0.0, wrapping at 4096), and
local and Linux builds read a checked-in 0.1.0.
**Change.** `VERSION` holds `major.minor.patch`; premake writes the git-ignored `BuildInfo.h` from it
(`DE_VERSION` overrides for a tag), and CI sets only `DE_BUILD_NUMBER`.

### A107 — Events {#a107}
The unscoped `EventCategory` injected `Dingo::None` and seven names, `IsInCategory` wasn't const and
had no callers, `MouseButtonEvent` lacked its category, and `GetRepeatCount()` was only ever 0 or 1.
**Change.** `enum class EventCategory : uint32_t` with `|`/`&`, `DE_EVENT_CLASS_CATEGORY(Mouse | MouseButton | Input)`,
const `IsInCategory`, `KeyPressedEvent::IsRepeat()`.

### A108 — `Button` alias {#a108}
The unused `typedef ... Button` made `Button("Play")` ambiguous with `UI::Button` under two
`using namespace`s. **Change:** removed.

### A109 — Leaky macros {#a109}
`BIT(x)` (no prefix, no parentheses), `EVENT_CLASS_TYPE/CATEGORY`, unused `DE_EXPAND_MACRO` and
`DE_STRINGIFY_MACRO`, and asserts expanding to `{ ... }` (an `if/else` around them failed).
**Change.** `DE_BIT`, `DE_EVENT_CLASS_*`, the two unused macros removed, `do { ... } while (0)`.

### A110 — ImGui names {#a110}
`EnableUI`, `UIParams` and `OnUIRender` meant the ImGui debug UI, and DingoUI (§2.8) brings a game UI.
A field rename can't carry a deprecated alias through designated initializers, so it was now or 2.0.
**Change.** `EnableImGui`, `ImGuiParams` (`UI/ImGuiParams.h`), `Layer::OnImGuiRender`.

### A111 — `FileSystem` image reads {#a111}
`ReadImage`/`ReadImageFromMemory` returned an owning `const uint8_t*` for `FreeImage`, with three
out-parameters; `GetFileName` was dead.
**Change.** `FileSystem::ReadImage(path, flip, forceRGBA)` returns `std::optional<ImageData>`; the raw
readers are `Internal` (`Core/FileReaders.h`); `GetFileName` removed. `WriteImage` stays.

### A112 — Asset metadata {#a112}
**Change.** `AssetMetadata` keeps `Handle`, `Type`, `FilePath`, `State`; the bookkeeping is in
`Internal::AssetRecord`. `GetHandles()` replaces `GetRegistry()`. `k_InvalidAsset` is `constexpr`.

### A113 — Debug panels {#a113}
**Change.** Every section and window function moved to `src/DingoEngine/UI/DebugPanels.h`
(`Internal`), with `Internal::DebugTab`.

### A114 — `GraphicsAPI::Headless` {#a114}
A value-initialized `GraphicsAPI{}` was Headless, which `GraphicsContext::Create` always rejected
fatally. **Change:** removed; `Vulkan` is 0. Superseded by the #244 merge (1d7a9fa): Headless is kept as the last enumerator, so `GraphicsAPI{}` stays Vulkan.

### A115 — Dead declarations {#a115}
**Change:** `Core/Memory.h`, `Core/IO.h` (`WriteFileAtomic`, 0 callers), `PopLayer`/`PopOverlay`,
`AudioEngine::As<T>` and `UIParams`' commented-out fields deleted.

### A116 — Naming drift {#a116}
**Deprecate.** `ToString(AssetType/AssetState/WindowMode)`, `k_MaxGamepads`, `k_GamepadButtonCount`,
`k_GamepadAxisCount` and `Application::IsUpdatingInBackground()` added; the old names are
`[[deprecated]]` inline forwards until 2.0. Every in-tree use moved.

### A117 — Aggregate params {#a117}
Games build `ApplicationParams`, `WindowParams` and the rest with designated initializers, so member
order is API. **Keep**, with the rule in versioning.md: members append-only, never reordered or
removed, no user-declared constructors. Also kept: `SaveData`/`Settings`' optional reads with an
error string, `Ray`'s `bool` + out-hit (matches `Physics3D::RayCast`); `Input::IsGamepadButtonUp` can
come in a minor release.

## Graphics (A2)

### A201 — One lifetime rule {#a201}
Release differed by type: `DestroyAndDelete` for most, a special overload for `GraphicsBuffer`
(protected destructor), plain `delete` for `Mesh` and `ParticleEffect`, either for `Material`, `Model`
and `Font`, `Shutdown` + `delete` for the renderers. A plain `delete` of a `Framebuffer` leaked its
attachment textures. `Initialize()` was public, and a second call leaked.
**Change.** A factory returns a ready object or `nullptr`, `delete` frees everything
([docs/conventions.md](../../docs/conventions.md)):
- `~NvrhiFramebuffer` runs `Destroy`, which frees its attachments; the other backends' destructors
  already dropped every handle.
- `~Renderer2D` and `~Renderer3D` call their idempotent `Shutdown`.
- `GraphicsBuffer`'s destructor is public, so its `DestroyAndDelete` overload is gone, and
  `DestroyAndDelete` is plain delete-and-null.
- `Initialize()` is protected on every resource base (private on the renderers and `Font`, whose
  constructor and `GetMSDFData` are private too). The swap-chain framebuffers' own factories
  initialize.
- `Destroy()`/`Shutdown()` stay public as an early GPU release.

### A202 — `Renderer`'s frame control {#a202}
`Initialize`, `Shutdown`, `Destroy`, `BeginFrame`, `EndFrame`, `SkipFrame`, `QueueResize`,
`QueueVSync`, `Begin`, `Close`, `Execute`, `GetCommandList`, `TryGetRecordingCommandList`,
`IsSwapChainFramebuffer` and `GetSwapChainResizeGeneration` were public. Their only callers outside
`src/` were five legacy tests commented out in `TestLayer.cpp`, which called `Begin`/`Close` inside the
frame `BeginFrame` had opened.
**Change.** Private, reached through `Internal::RendererBackend` (`Graphics/RendererBackend.h`).
`IsFrameSkipped` stays public. The commented-out tests (StaticTriangle, VertexBuffer, IndexBuffer,
UniformBuffer, Texture, Renderer) are deleted rather than revived: every one is covered by a live
test (Mesh 3D, Batch, Render Target).

### A203 — `Material`'s renderer plumbing {#a203}
`SetSceneUniformBuffer`, `SetSkinUniformBuffer`, `SetSkinPaletteBuffers`, `SetShadowResources`,
`SetObjectBuffer`, `SetInstanceBuffers`, `GetUniformBuffer`, `GetUniformCPUData`,
`NeedsUniformUpload`, `MarkUniformUploaded` and `GetOrCreateRenderPass`: 30 call sites, all in
`src/`; a game calling them would desync the renderer's binding caches.
**Change.** Private, behind `Internal::MaterialAccess` (`Graphics/MaterialAccess.h`). The `k_*Name`
constants stay public: they name the GLSL blocks custom shaders declare.

### A204 — `Texture::Upload(data, size)` {#a204}
`size` was forwarded as `writeTexture`'s row pitch, while `GraphicsBuffer::Upload(data, size)` takes
a byte count. **Change:** `Texture::Upload(const void* data)` uploads the whole image, the pitch derived
from the width and format.

### A205 — `CullMode::BackAndFront` {#a205}
The name said "cull both", the value was `None`. **Change:** removed; `None`.

### A206 — Dead knobs {#a206}
**Change:** removed `GraphicsParams::FramesInFlight` (never read; Vulkan hard-codes 2),
`Renderer2DParams::ClearColor` (only written), `TextureParams::WrapMode`/`TextureWrapMode` (address
modes live on `SamplerParams`) and `Renderer2D::GetOutput()` (always null).

### A207 — `TextureFormat::RGB` and `RGBA` {#a207}
`RGB` made an RGBA8 texture but uploaded at a 3-byte pitch; `RGBA` duplicated `RGBA8_UNORM`, so
readback tested both. **Change:** `RGB` removed, `RGBA = RGBA8_UNORM` (an alias), `RGBA8_UNORM` the
`CreateFromData` default.

### A208 — Sibling params disagree {#a208}
`MaterialParams::Blend`/`DepthFunction` beside `SetBlendMode`/`SetDepthCompare` and
`PipelineParams::BlendMode`/`DepthCompare`; `PipelineParams::FrontCounterClockwise` defaulted to
`false`, `MaterialParams`' to `true`.
**Change.** `Dingo::BlendMode BlendMode`, `Dingo::DepthCompare DepthCompare`; the pipeline default is
`true`. Renderer2D's batch pipelines set `false` themselves (see the fix status).

### A209 — Backend types in public params {#a209}
**Change.** `GraphicsParams::NativeWindowHandle` removed (the window goes to the private
`GraphicsContext::Create(params, window)`); `SwapChain`/`SwapChainParams` are `Internal` under `src/`
(their setters return a reference); `Application::GetSwapChain()` removed (`Renderer::GetSwapChainFramebuffer()`
covers the one test that read it); `GraphicsContext`'s constructor, `Initialize`, `Shutdown` and
`RunGarbageCollection` are not public.

### A210 — `SkinData` skinning {#a210}
The `DE_SKIN_PALETTE` arena (v1.0 P6) replaces it; no example uses it.
**Deprecate.** `Renderer3D::k_MaxSkinDataBinding` (→ `k_MaxSkinUniformBinding`, which also bounds
`DE_SkinDraw`), `k_MaxSkinDataInstances` and `Material::k_SkinDataBlockName` are `[[deprecated]]`; the
renderer warns once when a material skins through a `SkinData` block; docs/animation.md marks it.
About 200 lines of Renderer3D go in 2.0.

### A211 — `Renderer3D::SetDirectionalLight` {#a211}
**Deprecate**, pointing at `SubmitLight`/`SetAmbientLight` per scene or `Renderer3DParams::LightDirection/Ambient`.
The Batch Test's one call set the defaults it already had and is gone.

### A212 — No PIMPL {#a212}
`Renderer3D.h` is 60 % private members, `Renderer2D.h` and `Animator.h` similar. Games can't name
them, and `Renderer2D/3D` are made only through `Create`.
**Keep.** versioning.md says the promise is source compatibility, not ABI. A `Renderer3DImpl` can come
in a 1.x minor (about 60 forwarders, no call-site changes); `Animator` must stay copyable, so not it.

### A213 — `[[nodiscard]]` {#a213}
**Change.** On every raw factory (`Create*`, `LoadFromFile`, `CreateLitMaterial`, `Renderer2D/3D::Create`),
`CreateParticleEmitter`, `CreateStaticBatch`, `AABB::Transformed`, `Frustum::FromViewProjection`,
`AudioEngine::LoadClip`/`CreateBus` and the (now internal) `CommandList::SetPipeline/SetRenderPass`.
Not on `StaticBatch::Add`, whose id a batch filled once and never edited doesn't need (the Batch
Test does exactly that), nor on `SceneManager::CreateScene` (the manager owns the scene).

### A214 — `SubMesh::MeshData` / `Mat` {#a214}
**Change:** `Dingo::Mesh* Mesh`, `Dingo::Material* Material`, as on `StaticMesh` and every component.

### A215 — Self-describing parameters {#a215}
**Change.**
- `SamplerFilter { Nearest, Linear }` for `SamplerParams::Min/Mag/MipFilter`, plus `SetFilter` for all three.
- `GraphicsFormat` (only ever an index type) became `IndexFormat { Uint16, Uint32 }`:
  `CreateIndexBuffer(size, IndexFormat, data, upload, name)` takes it before the defaulted
  arguments, and `GraphicsBufferParams::IndexFormat` defaults to `Uint32` (meshes are 32-bit).
- `BufferUpload { Direct, Deferred }` replaces `bool directUpload` and `GraphicsBufferParams::DirectUpload`.

### A216 — `SubmitMesh`'s 8 arguments {#a216}
**Keep.** Appending a defaulted argument is SemVer-safe; the order is frozen (versioning.md). A
`SubmitMesh(const StaticMesh&, float cullDistance)` overload can come in a 1.x minor.

### A217 — `Shader::Create` never returns null {#a217}
The asset manager and hot-reload keep a live, invalid shader while its file is fixed. **Keep**, as the
one documented exception in conventions.md, with `IsValid()`.

### Internal moves in Graphics
Besides A202, A203 and A209: `CommandList` is `Internal::CommandList` under `src/` (its `Viewport`
struct moved to `Graphics/Viewport.h`), `ShaderType` moved under `src/` (no public API took it),
`Texture::NativeEquals` and `PostProcessStack::Shutdown` are private, and `Framebuffer.h`'s three
stale `friend` lines are gone. Kept public: `IBindableShaderResource` (a public base class),
`Texture::GetTextureHandle` (the ImGui image escape hatch the test viewport uses),
`GraphicsContext::As<T>` (harmless: the backend types aren't in `include/`) and
`Renderer3D::GetSkinnedVisibility` (returns an opaque `Internal` type; `Scene` reads it from a free
helper, so a friend can't reach it).

## Scene and physics (A3)

### A301 — The first `SetActiveScene` {#a301}
It only selected the scene; later switches started the new one. *SpaceInvaders* and *AngryBirds*
never started their first scene, so `PlayOnStart` audio and physics didn't run.
**Change.** Every `SetActiveScene` calls the idempotent `OnStart`; DungeonCrawler moves its
`SetActiveScene` after building the scene.

### A302 — One script per entity {#a302}
A second `AddScript` deleted the first without `OnDestroy`, and a script replacing itself was freed
mid-call. **Change.** One script per entity, documented: `AddScript` replaces after the old one's
`OnDestroy`, `Entity::RemoveScript` detaches, and detached scripts are freed at the end of the update.

### A303 — Runtime edits {#a303}
A body kept the type it was built with while the write-back read the component's current `Type`;
removing a body, controller or audio source component left the runtime object alive.
**Change.** The runtime structs keep the built type; `on_destroy` hooks release the runtime object.
Rule documented: settings components are read when their runtime object is built, and
`SetActive(false/true)` is the rebuild path.

### A304 — Another scene's entity {#a304}
`DestroyEntity` and `CreateRigidBody` checked `!entity` and then used the handle in their own
registry. **Change:** both use `IsValid(entity)`.

### A305 — `DirectionalLightComponent::Ambient` {#a305}
Deprecating the member alone would warn only those who had migrated (`Ambient = 0`).
**Change.** The default is 0 and the member `[[deprecated]]`; every example and test moved to an
`AmbientLightComponent` with the same look (the engine's own default light keeps 0.35).

### A306 — `OnFixedUpdate` and physics {#a306}
The plan's "physics step accumulator" doesn't exist: 3D steps the variable delta in
`ceil(dt * 60 - 0.1)` collision steps, 2D with 4 substeps.
**Keep.** Physics stays on the variable step through 1.x; `OnFixedUpdate` runs from a separate
accumulator for game logic (versioning.md "Simulation timing"). A fixed-step physics mode can come as
an opt-in.

### A307 — 2D getters {#a307}
**Change:** `GetLinearVelocity2D`, `GetGravity2D` beside the `*3D` ones.

### A308 — `BoxCollider2DComponent::Size` {#a308}
A half-extent fraction named like `TransformComponent::Size`, the full extent. **Change:**
`HalfExtents`, as in 3D.

### A309 — `Scene`'s engine-only calls {#a309}
**Change.** `Entity GetPrimaryCamera()` added; `GetRenderCameras` moved into `Internal::CameraUtils`;
`GetFirstDirectionalLightEntity` (0 callers) deleted; the transition queries private.

### A310 — `OnPhysicsStart/Stop` {#a310}
They bypassed `OnStart` and were taught in two docs. **Deprecate**; the docs teach `OnStart`/`OnStop`.

### A311 — `Physics2D/3D::As<T>` {#a311}
**Change:** removed (0 callers; the backend classes are in `src/`).

### A312 — `Entity` holes {#a312}
**Change.** No `Add/RemoveComponent<IDComponent|TagComponent>` instantiations; `SetName`;
`HasComponent`/`RemoveComponent` are safe on an invalid entity and `GetComponent` asserts with the
type's name.

### A313 — 2D body ids {#a313}
**Keep** the typedefs (strong types aren't worth the breakage); `k_InvalidBody2D = 0` added.

### A314 — Raw resource pointers in components {#a314}
**Keep**, with the rule in conventions.md: component pointers don't own.

### A315 — 2D/3D naming {#a315}
Components leave the 2D name bare, `Entity`'s world-transform calls the 3D one. **Keep** (174 sites);
both rules are in conventions.md.

### A316 — `Scene::GetEntityFromBody2D` {#a316}
The plan asked for it "only if the audit keeps it". Its 3D twin answers a ray cast's or sensor's
body id, but `Physics2D` has no queries (no ray casts, no overlaps) that hand a game a body id to look
up, and `RigidBodyParams2D` has no user data. **Not added**; it is an addition, so a 1.x minor can
bring it with 2D queries and user data.
